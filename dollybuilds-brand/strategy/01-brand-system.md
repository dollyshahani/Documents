# The dollybuilds Visual System
### "a dream garden, kept in a journal"

Cream-first so burnout content stays calm · butter + pearl for the dreamy glow · plum for depth · honey for warmth. Handwritten + clean sans so every post sounds like you. Doodle florals by day, glitter blooms at night.

## Palette
| Color | Hex | Job |
|---|---|---|
| Paper | `#F7F1E3` | Default background of every post |
| Butter | `#F6E7A6` | Soft / dreamy backgrounds (with radial glow) |
| Ink | `#1B1B18` | All body text |
| Plum | `#43395F` | Headers, serious accents, frames |
| Honey gold | `#DCAF6E` | CTA buttons, sparkles, flower centers |
| Rose pink | `#F2A9C4` | Blooms, handwritten emphasis |
| Lilac | `#D8CCEF` | Soft accents, story highlights |
| Pearl shimmer | gradient `#F9D8E5→#E3D9F6→#CFEAF0→#F8ECC8` | Dreamy moments ONLY — texture, never flat |

## Typography
- **Caveat (Bold)** = feelings, hooks, the ONE emphasized word.
- **Poppins (Light/Regular + SemiBold)** = facts, lists, captions, labels.
- Never swap their jobs.

## Two element families
- **Doodle family** (pen bloom, thin plum stem, rose-pink head, honey center) → burnout, ADHD, tips, carousels.
- **Shimmer/collage family** (pearl & water photo textures + pearls, shells, hibiscus, sparkles) → manifestation, affirmations, milestones.

## The 7 rules
1. Cream first; butter for soft; solid color-blocks only for announcements / profile anchor.
2. One bloom per post — never a bouquet. Doodle on practical posts, glitter on dreamy.
3. Handwriting = feelings, sans = facts.
4. Shimmer is earned, not sprinkled — dreamy posts only, max 2–3 sparkles.
5. One warm preset for every travel photo — same light, same world. Caption in Caveat.
6. Serious earns plum, joy earns pink, dreams earn shimmer.
7. Landing pages inherit everything — paper bg, plum headers, honey buttons, one bloom per section, one shimmer hero moment.
